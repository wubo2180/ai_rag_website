# OCR适配器架构设计文档

## 🎯 设计目标

1. **统一接口**: 所有OCR服务必须遵循统一的请求/响应格式
2. **适配器模式**: 每个OCR模型对应一个适配器类，负责数据解析和存储
3. **配置化管理**: 通过系统配置关联文件类型、OCR服务、适配器、页面和数据表
4. **易于扩展**: 新增OCR模型只需实现适配器接口和配置即可

## 🏗️ 架构设计

```
┌─────────────────────────────────────────────────────────────────┐
│                    系统配置管理                                   │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  DocumentTypeConfig (文档类型配置表)                       │  │
│  │  - document_type_code (委托单/论文/检测报告...)             │  │
│  │  - ocr_service_url (OCR服务URL)                           │  │
│  │  - adapter_class (适配器类名)                              │  │
│  │  - recognize_page_component (识别页面组件)                 │  │
│  │  - review_page_component (核对页面组件)                    │  │
│  │  - data_model_class (数据模型类名)                         │  │
│  │  - is_active (是否启用)                                    │  │
│  └───────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                   统一OCR服务接口                                 │
│  所有OCR服务必须实现的标准接口:                                   │
│  POST /api/analyze                                               │
│  Request: { file: File }                                         │
│  Response: {                                                     │
│    "success": true,                                              │
│    "message": "识别成功",                                         │
│    "data": { ... }  // 由各服务定义的数据格式                     │
│  }                                                               │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                   适配器基类 (BaseOCRAdapter)                     │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  抽象方法:                                                  │  │
│  │  - parse_ocr_result(raw_data) -> structured_data          │  │
│  │  - save_to_database(structured_data, file_id) -> bool     │  │
│  │  - get_from_database(file_id) -> structured_data          │  │
│  │  - validate_data(structured_data) -> (bool, errors)       │  │
│  └───────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
          ↓                    ↓                    ↓
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│ CommissionAdapter│  │   PaperAdapter   │  │  ReportAdapter   │
│                  │  │                  │  │  (未来扩展)       │
│ 委托单数据解析    │  │  论文数据解析     │  │                  │
│ CommissionBasic  │  │  PaperArticle    │  │  ReportData      │
│ TestItem         │  │  PaperMaterial   │  │  ...             │
│ SpecialTest      │  │  PaperProperty   │  │                  │
└──────────────────┘  └──────────────────┘  └──────────────────┘
